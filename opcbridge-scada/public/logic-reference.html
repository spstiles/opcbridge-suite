Logic Reference

Function examples and operator support for Logic Blocks and Scripts.
Operators
Arithmetic: + - * / %
Comparison: == != < <= > >=
Boolean: && || !
Grouping: ( ... )
Tag Functions
tag("PLC1", "RawFlow") — Reads current tag value (number/string/bool).
quality("PLC1", "RawFlow") — Reads numeric quality code (good usually 1).
hasTag("PLC1", "RawFlow") — True if tag exists in runtime.
setTag("_memory", "FlowScaled", 12.3) — Writes evaluated value to writable destination tag.
JSON
json(payload, "flow.raw", 0) — Reads JSON path value. If path/parse fails and default is provided, returns default.
hasJson(payload, "flow.raw") — True if payload parses and path exists.
jsonSet(base, "key", value) — Returns JSON object string with key updated. Empty/invalid base starts as {}.
jsonObj("seconds", 15, "ok", true) — Builds JSON object string from key/value pairs.
jsonArray(1, 2, "x", true) — Builds JSON array string from arguments.
Math
map(raw, 0, 4095, 0, 100) — Linear scale from one range to another.
clamp(value, 0, 100) — Limits value to min/max bounds.
round(value, 1) — Rounds to decimal places.
min(a, b, c) / max(a, b, c) — Smallest/largest numeric argument.
Bits
bit(statusWord, 3) — True if bit N is set.
bits(statusWord, 0x00FF) — Bitwise AND with mask; useful for packed status checks.
Strings / Conversion
str(value) — Converts value to string.
num("123.4", 0) or number("123.4", 0) — Converts to number; uses default on failure.
bool("true", false) — Converts to bool; uses default on failure.
concat("A", "-", "B") — Concatenates values as strings.
lower(text) upper(text) trim(text) — String normalization helpers.
contains(text, "x") startsWith(text, "x") endsWith(text, "x") — String match checks.
Notes
json() without default throws a validation/runtime error when path is missing or payload is invalid JSON.
hasJson() is the safe guard before reading optional JSON fields.
setTag() writes only to writable tags; system tags are read-only.
Control Flow
if (quality("PLC1", "Run") == 1) {
	setTag("_memory", "RunOk", true);
} else {
	setTag("_memory", "RunOk", false);
}
